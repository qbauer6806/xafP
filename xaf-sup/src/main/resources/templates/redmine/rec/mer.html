curl -H "Content-Type: application/json" -H "Authorization: [[file-api.back.jwt]]" --request POST --data '{"basedir" : "/www/data/file/${TSCODE}"}' http://as-api-1-rec.monaco-gouvernement.mc:30490/file/api/v1/file/${TSCODE}

Création du container ROOT : Exécuter la commande (En remplaçant [[file-api.back.jwt]] )  :

curl -H "Content-Type: application/json" -H "Authorization: [[file-api.back.jwt]]" --request POST  http://as-api-1-rec.monaco-gouvernement.mc:30490/file/api/v1/file/${TSCODE}/ROOT

A partir de la version XAF 7.1.0

Création d'un container MODELES

curl -H "Content-Type: application/json" -H "Authorization: [[file-api.back.jwt]]" --request POST  http://as-api-1-rec.monaco-gouvernement.mc:30490/file/api/v1/file/${TSCODE}/MODELES

                --form 'data=@@/${tscode}/${tscode}-shared/src/main/resources/modeles/[[FichierModele]].docx'
